# 严复译注

查阅：2026-10-27（北京时间），公开页 `https://zhangqian.caojuege.com/`。当日页面与仓库 `site/index.html` 一致。路径：中文原页 → 中文市场（中→中）。目标读者沿用原页：已经上线、还没找到第一批付费用户的独立开发者；已有用户也可以从他们开始。

## 信
- 原始价值主张：让市场告诉你谁愿意为你付钱。做法是一页行动单加一个小实验，不替用户改定位、不保证找到人。
- 忠实保留：前十个海外付费用户、三样输入、一个主实验、七天观察、每天约二十分钟、六级读数和四条记分规则、四种走法的正文、不做投放不刷量、安装步骤和那句可粘贴的提示词、张骞凿空的原句、七十六分和「没有自家银票」、David 与草诀歌 AI Labs。下载和 GitHub 链接未改。
- 表达依据：以上句子都能在公开页对上。七天和「两周内能被证伪」都按原句留在原处，没有合成新的时间窗。
- 因证据不足未使用：没有写成已经找到付费用户，没有把 InkDao 写成完成的案例，没有把七十六分写成推荐，没有补客户、媒体、价格或英文服务。

## 达
- 最终一句话 Pitch：产品上线了，还不知道谁付钱。把链接交给张骞，先拿一页今天能发出去的行动单。
- 故事主线：你是谁 → 今天做什么 → 什么才算数 → 七天后四种走法 → 它明确不做什么 → 怎么安装。
- 信息顺序调整：原页第一眼是超大竖排「张骞」和西行画，产品那句话在下面。上一稿把句子塞进左侧，巨字还在，打开仍像原页。这一稿让「让市场告诉你，谁愿意为你付钱」成为首屏最大的字，旁边是西行画；「3 个输入、1 个主实验、7 天、20 分钟」跟着这句话。竖排品名挪到「为什么叫张骞」，和名字的来历放在一起。验证包前仍写明：流量可以写没有，人群可以写不知道。
- 删除、合并或弱化：没有删区块，也没有为了凑齐模板去写问答。附录里的「埋点」改成「怎样记下使用和付款」；「激活」改成「有人开始用」，四种走法里对应的「没激活」也改成「没开始用」。四种走法里，只有标题「补探针」改成「先收定金」，底下仍写先补预售或定金。云纹让出了左侧空位，避免压住按钮。

## 电梯演讲
- 30 秒版本：张骞是一个技能，给已经上线、还不知道谁会付钱的独立开发者。你交出产品链接、流量从哪来、你猜谁需要它。它不改你的页面，给你一页行动单和一段能直接发出去的话。你按它去做，每天大约二十分钟，观察满七天。点赞和「看起来不错」不算。对方说出具体场景、真的用了，或把钱付过来，才算数。它不保证你找到那十个海外付费用户。第一轮判负，也是在告诉你下一轮该带什么。
- 使用场景：下载前讲给同行听；解释它为什么不是营销方案。
- 不应越界承诺：不保证找到十个人；不承诺改文案就会有人买；免费使用不等于愿意付钱；七十六分不是客户证明；InkDao 还没有公开的付款读数。
