# 张骞 · 找到你的前 10 个海外付费用户

把“谁会要你的产品”变成低成本小实验。先看一页行动单，先跑一个实验，再按真实读数决定下一步。

适合产品已经上线，却还不知道第一批付费用户在哪里的独立开发者。已经有人用、还不清楚谁愿意付钱，也可以从现有用户开始测。

## 它会交付什么

- **一页行动单**：这轮测什么、先找谁、今天做什么、看到什么才继续。
- **一个主实验**：按“找谁 → 怎么找 → 直接发这段 → 记录什么 → 下一步”展开，含成本和目标市场语言文案。
- **七天安排与一张记录表**：把激活、实际使用和付款分开记，按完整观察窗口判断。
- **一张结果判断表**：区分有苗头、有人付款、流程中断和样本不足。
- **按需查的附录**：1–2 个备选实验、完整 UTM 链接、激活与付费事件、补充付费探针和研究依据。

每轮输出一个 Markdown 文件：`{产品名}-验证包-第{N}轮.md`。下一轮把记录表交回来，继续验证。

默认准备 2–3 个实验，但先启动主实验；备选按读数和触发条件启动。已有真实用户时，优先回访他们的具体任务。开跑前仍需确认页面可用、链接可追踪、激活和付款可记录。

## 安装

### 下载技能包

下载 [zhangqian.skill](https://github.com/ShaohuaDavidLee/zhangqian/raw/refs/heads/main/zhangqian.skill)，在支持导入 `.skill` 文件的工具中安装。

### 手动安装

下载本仓库的 [SKILL.md](./SKILL.md)，放入所用工具的技能目录，保持如下结构：

```text
zhangqian/
└── SKILL.md
```

例如，Codex 的个人技能目录可放在 `~/.codex/skills/zhangqian/SKILL.md`；Claude Code 可放在 `~/.claude/skills/zhangqian/SKILL.md`。安装后重新打开会话，让工具发现技能。

## 开始使用

在安装了技能的 AI 工具中输入：

> 用张骞帮我找第一批海外付费用户。产品链接是【你的产品链接】；目前的用户或流量来自【来源，也可以写没有】；我猜最需要它的人是【最多 3 类，也可以写不知道】。

只需要三个输入：产品链接、现有用户或流量来源、你猜测的目标人群。AI 需要能够读取产品网页；实验发布、埋点和收款需要在你实际使用的平台完成。

## 什么读数算数

| 级别 | 读数 |
| --- | --- |
| 0 · 不算 | 曝光、浏览、点赞、收藏、点击、“看起来不错” |
| 1 · 原话 | 目标用户说出具体需求或场景 |
| 2 · 行动 | 完成核心动作、主动问价格、留下联系方式等开通 |
| 3 · 留存 | 隔周回来用、用尽免费额度、真正使用生成结果 |
| 4 · 付钱 | 首笔付款到账，包括预售、定金、付费排队 |
| 5 · 回头 | 续费、复购，或自发带来付费用户 |

免费使用最高算 3 级，不能证明有人愿意付钱。退款或拒付期内的付款需单独标注；定制或服务订单收首款算 4 级，交付并结清才算 5 级。完整规则见 [SKILL.md](./SKILL.md)。

## 工作边界

默认预算接近零，日常维护按每天 20 分钟设计。不建议付费投放，不做刷量、假评论或夸大承诺。

先按产品现状测试，只处理坏链接、错价格等阻断项。有访问、无激活时，先查中断环节，再根据证据决定是否调整页面。连续两轮在样本充分、流程正常的情况下全部判负，就停下来重新审视需求；未启动的备选不算失败。

张骞不保证找到付费用户；判负也是有效答案。

## 落地页与部署

线上地址：[zhangqian.caojuege.com](https://zhangqian.caojuege.com/)。

`site/` 是可直接部署的静态页面，保留水墨版式与完整文案。Hero 使用敦煌西行插画，四周以 CSS 透明蒙版融入纸色；结尾使用大夏市集插画。页面不依赖 React 或设计工具的预览运行时。

本地预览：

```sh
python3 -m http.server 8766 --directory site
```

部署到 Cloudflare Workers Static Assets（先在本机登录 Cloudflare）：

```sh
npx wrangler@4.151.3 deploy
```

`wrangler.jsonc` 配置了静态目录及 `zhangqian.caojuege.com` 自定义域名。
